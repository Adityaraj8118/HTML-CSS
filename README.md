# HTML & CSS

Static web pages I built while learning HTML, CSS and basic JavaScript.

| File | Description |
|---|---|
| `About_me.html` | Personal "About Me" page with a header, content sections and footer, styled with internal CSS |
| `Interactive_webpage.html` | Page with a button that shows a message and a contact form handled with JavaScript (client-side only, no data is sent) |
| `test.html` | Basic test page |

## Viewing

No setup needed. Download or clone the repository and open any `.html` file in a browser.
